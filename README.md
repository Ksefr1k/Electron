# Electron — Minecraft Java launcher

Кастомный лаунчер Minecraft Java Edition с настраиваемыми темами, каталогом модов Modrinth, версиями Minecraft, Microsoft/офлайн-аккаунтами, скинами и автоматической установкой Java и загрузчиков Fabric, Forge, NeoForge и Quilt.

## Запуск из исходников

1. Установите Node.js LTS.
2. В папке проекта выполните:

```bash
npm install
npm start
```

## Сборка в EXE

```bash
npm run build
```

Установщик появится в папке `dist/`.

## Возможности

- **Minecraft** — релизы, снапшоты, beta/alpha и установленные профили загрузчиков.
- **Fabric, Forge, NeoForge и Quilt** — установка стабильного Fabric/Quilt, рекомендованного Forge или последней стабильной версии NeoForge для выбранного Minecraft. NeoForge ставится официальным установщиком при первом запуске (нужна Java, занимает несколько минут). Quilt использует моды Fabric (вместо Fabric API ставится Quilted Fabric API). Модпаки Modrinth (.mrpack) на всех четырёх загрузчиках ставятся с версией загрузчика, указанной в сборке. Первый запуск конкретной сборки докачивает игровые файлы и библиотеки.
- **Аккаунты** — Microsoft с обновлением сессии или офлайн-ник 3–16 символов (`A–Z`, `0–9`, `_`).
- **Скины** — загрузка скинов Microsoft-аккаунта; для офлайн-аккаунта — локальный PNG с предпросмотром. Чтобы локальный скин показывался в игре, выберите профиль Fabric/Forge и нажмите в окне скина «Установить поддержку в выбранную сборку». Лаунчер скачает совместимый CustomSkinLoader с Modrinth и положит скин в локальную папку. Локальный скин не станет официальным скином Microsoft и не будет виден другим игрокам без совместимой системы скинов.
- **Java** — автоматический подбор по версии Minecraft. На Windows при отсутствии нужной Java лаунчер получает подходящий JDK Eclipse Temurin через API Adoptium, проверяет размер и SHA-256 архива, повторяет неудачную загрузку до трёх раз и проверяет Java перед установкой. Для Windows x64 скачивается x64, для x86 — x86.
- **Horizon (Rust)** — установка и запуск неофициального клиента [Horizon](https://github.com/horizon-rust/horizon) (только Windows x64). Во вкладке «Horizon» есть каталог **модов, ресурспаков и шейдеров из реестра Horizon** с установкой, включением/выключением и удалением. Лаунчер ставит только то, что Horizon умеет запускать: проверяет контрольную сумму, подпись автора и возможности мода. Java-моды (Fabric, Forge, NeoForge) в Horizon не работают и сюда не попадают.
- **Моды** — поиск в каталоге Modrinth с фильтрацией по выбранной версии Minecraft и загрузчику, установка совместимых JAR-файлов, список установленных, включение/отключение и удаление. **Обязательные зависимости** (например, Fabric API или библиотеки) скачиваются автоматически и рекурсивно; уже установленные моды, в том числе добавленные вручную, опознаются по хешу и не дублируются.
- **Шейдеры и ресурспаки** — отдельные вкладки на странице «Моды». Файлы попадают в `shaderpacks` и `resourcepacks`, работают и на чистой версии Minecraft. Для шейдеров на Fabric вместе с первым паком автоматически ставится Iris (с Sodium). Если точной версии под вашу сборку нет, ставится ближайшая с предупреждением. CurseForge не подключён.
- **Темы** — зелёная (по умолчанию), светлая, тёмная, OLED-чёрная, фиолетовая, океан и закат. Переключатель находится в правой части верхней панели рядом с аккаунтом; выбор сохраняется между запусками.
- **Настройки** — максимальная/минимальная RAM, выбор Java вручную, папка игры, размер окна, полноэкранный режим, JVM-аргументы и консоль логов.

## Папки данных

- Игра, версии, моды и миры: по умолчанию `%APPDATA%\\.mylauncher`.
- Настройки, лог и скачанная лаунчером Java: каталог `userData` Electron.
- Локальные скины офлайн-профилей сохраняются в `userData/skins`, затем копируются в папку выбранной игры.

## Примечания

- Для первого запуска Minecraft, Fabric/Forge и модов требуется интернет.
- Рекомендуется сначала выбрать базовую версию Minecraft, затем установить для неё Fabric или Forge. После установки профиль будет выбран автоматически.
- **Отдельная папка для каждой сборки** (включена по умолчанию, переключатель в «Настройки → Игра»): моды, шейдеры, ресурспаки, конфиги, миры и офлайн-скины лежат в `<папка игры>\\instances\\<сборка>`. Общими остаются только версии, библиотеки и ресурсы Minecraft, поэтому место не дублируется. Файлы из старой общей папки можно перенести кнопкой «Скопировать» на странице модов.
- **Обновления модов** — проверка по хешам через Modrinth (запускается сама при открытии страницы), обновление одного мода или всех сразу; состояние «включён/отключён» сохраняется, новые обязательные зависимости докачиваются.

- **Новые версии Minecraft и снапшоты** подтягиваются из манифеста Mojang при запуске и каждые 30 минут; при выходе новой версии или снапшота появляется уведомление (снапшоты — в фильтре «Снапшоты»).
- **Выбор версии мода**: кнопка «Версии» на карточке показывает все версии проекта; подходящие для твоей сборки помечены ✓, остальные ⚠ (ставятся только после подтверждения).
- **Совместимость**: установленные файлы, которые не заявлены для версии игры или загрузчика сборки, помечаются ⚠ в списке, а пустая выдача объясняет, что проект может ещё не поддерживать эту версию.

- **Язык и панель** — кнопка RU/EN в верхней панели и «Настройки → Интерфейс»: язык (русский/English) и вид левой панели (компактная по умолчанию, с подписями или вкладки сверху). Кнопка внизу панели быстро показывает подписи.
- **Horizon: Nightly** — с 28.10.2026 Horizon выпускает только Nightly (релиз `nightly`, помеченный как pre-release). Лаунчер ставит его как `nightly-<дата>-<коммит>`; если Nightly нет, берёт последний обычный релиз. Кнопка «Установить / обновить» ставит свежий Nightly.
- **Встроенные моды Horizon** — вкладка «Встроенные» на странице Horizon: **Lux Lamps** (4 цветные лампы) и **Ruby & Sapphire** (самоцветы, блоки, мечи и кирки; самоцвет крафтится из алмаза и блока красного камня/лазурита). Ставятся без интернета и сразу включаются. Кнопка «Добавить свой .hmod…» ставит любой контентный мод Horizon с диска. Исходники и сборщик: `horizon-bundled/build.py` (`python build.py` пересоберёт `.hmod`).
- **Моды Horizon** — перед каждым запуском лаунчер заново записывает `horizon-mods.txt`, чтобы включённые моды не терялись. Нативные моды (.hnmod) заработают только в игре, собранной с ними; Java-моды в Horizon не работают.
